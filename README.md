# 📊 Swiggy Sales Data Analysis – Excel Project

An Excel-based **sales analysis and dashboard project** designed to analyze Swiggy food-order data and generate meaningful business insights.

## 🎯 What It Does

- Analyzes **sales, orders, ratings and average order value**
- Performs **monthly sales trend analysis**
- Compares **state-wise sales performance**
- Analyzes **customer ratings and food categories**
- Presents insights through an **interactive Excel dashboard**

## 🛠️ Tools & Skills

**Microsoft Excel | Data Analysis | Pivot Tables | Dashboard | Data Visualization | KPI Analysis | Business Insights**

## 📌 Key Highlights

- Total Sales: **₹5.30 Crore+**
- Orders Analyzed: **197K+**
- Average Rating: **4.34**
- Average Order Value: **₹268.51**
- Includes monthly and state-level performance analysis

## 💡 Key Takeaway

Converted raw Swiggy sales data into **clear KPIs, visual insights and business-oriented analysis** using Excel.
